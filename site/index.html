Quick start

Get the cent in two minutes, no API key

You need Bun 1.3 or later and Chrome or Chromium. Nothing leaves your machine: the replay and the diff are plain code, and the browser can only reach the app under test.

# clone and install
git clone https://github.com/GlamgarOnDiscord/parity-agent.git
cd parity-agent
bun install

# the naive rebuild: the cent, field by field (exit code 1)
bun run prove
  ✗ Total: 69.21                   Total: $69.22
NO PARITY: differences above.

# the corrected rebuild
bun run prove --fixed
PARITY: every field matches.

# the one-page report, written to runs/report.html
bun run report --proof fixtures/proofs/vs3-invoice.json --fixture

prove and report exit with code 1 on a difference, like a failing test, so the same command gates a pull request. The repository ships a GitHub Action that does exactly that.

How it works

Five steps, and only one of them is judged by code.

  1. Record

    Someone narrates their use of the old app. Muse Voice Transcribe reads the narration, Muse Spark and SAM 3.1 read the fields on every key frame.

  2. Explore

    Muse Spark computer use drives the app alone, confined to it, and turns screens nobody recorded into replayable scenarios.

  3. Rules

    Business rules in plain language with their evidence; formulas are checked against the recorded values by code; an expert accepts or rejects each in a click.

  4. Rebuild

    Muse Code builds the web app from the accepted rules and repairs it difference by difference.

  5. Prove

    Every scenario is replayed and compared field by field. AI never decides what "the same" means: matching and comparison are plain code.

Models

Built with Meta models

Muse Spark reads screens and writes rules, Muse Spark computer use explores, Muse Wonder settles contradictions, Muse Code builds and repairs, SAM 3.1 finds fields on desktop frames, Muse Voice Transcribe reads the narration. Every call goes through a send log with its cost and the bytes sent, and stops at the budget you set.
